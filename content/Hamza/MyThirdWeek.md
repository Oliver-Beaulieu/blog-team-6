### Individual Contributions

Third phase had me building risk category routes while sketching Gabirel's frontend frames. Server logic began with a blueprint to organize risk data. Separate endpoints handled country ratings and their core info, others modified scores, tiers, or yearly notes. Getting updates right meant verifying essential fields early, crafting queries that hit precise records using country-year pairs, then smoothing how results were packaged before sending them back. Behind it all, tiny tasks such as validating inputs and polishing response formats quietly held everything together. Smooth outputs relied less on grand moves but more on disciplined little checks done consistently. Starting from Gabriel's Phase 2 drawings, the frontend took shape using Streamlit. One view allows picking among the 27 EU nations, switching scope from country down to region, following asylum trends through time. Another keeps stored contrasts handy for returning without starting over. Since initial layouts were fixed, along with prior alignment on how data flows, linking user moves to system responses became straightforward matching. Each tap leads precisely to expected results, made possible by steps taken before coding began.
